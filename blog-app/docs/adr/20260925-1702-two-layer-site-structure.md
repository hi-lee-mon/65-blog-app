# サイトを「母屋」と「展示室」の二層に分ける

- 日付: 2026-09-25
- 状態: 採用

## 背景

このブログの目的は三つある。見た目で遊ぶこと、技術力をアピールすること、新技術を試すこと。「ページごとに好きな見た目にしたい」と「技術を見に来た人に読みやすく見せたい」はぶつかる。

## 決定

サイトを二層に分ける。

- 母屋（`/`, `/about`, `/posts`, `/tags`, `/uses`, `/now`, `/colophon`）は共通のデザインシステムで統一する
- 展示室（`/lab/[slug]`, `/design-system`）はページごとに見た目も技術も自由にする。各 Lab ページの下部には「試したこと・学んだこと」を共通の枠で置く

## 理由

技術を見に来た人が読むページを統一すれば、読みにくさで離脱されない。遊ぶページを隔離すれば、一貫性がなくても全体は壊れない。展示室の作品は、そのまま技術力の証拠になる。

## 採らなかった案

- 全ページを自由にする: 訪問者が経歴や記事にたどり着きにくくなる
- 母屋をホームとプロフィールだけにする: 記事ページの読みやすさが保証できない
