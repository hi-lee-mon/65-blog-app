# 記事の正本は自サイトにする

- 日付: 2026-09-25
- 状態: 採用

## 背景

同じ記事を Zenn・Qiita・自サイトの3か所に配る（`20260925-1714-cross-post-articles.md`）。Zenn も Qiita も canonical（検索エンジンに正本を伝えるタグ）を設定できないので、どこを正本とするかを運用で示す必要がある。

## 決定

自サイトを正本にする。Zenn・Qiita 版の冒頭には、自サイトの記事へのリンクを置く。

## 理由

- 動くデモを見られるのは自サイトだけ
- 将来は自サイトだけに投稿する運用へ移る予定なので、最初から正本をそろえておく

## 採らなかった案

- 公開日をずらして Zenn を先に出し、Zenn を正本にする: 立ち上げ期は読者を集めやすいが、自サイトだけの運用へ移るときに正本が入れ替わる
