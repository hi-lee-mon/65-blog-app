このブログでは将来zennやqiitaにも同一の記事を投稿する予定です。（クロスポスト）

canonicalを設定することで、クロスポストが重複コンテンツであることをクローラーに教えることができます。

また、ブログページが増えてきたときに検索を追加する予定です。
例えば`/posts?q=react`や`/posts?sort=new`のようなURLがうまれることになりそうです。これにより大量のページが検索にインデックスされる可能性があります。
canonicalで/postsと設定しておけば検索エンジンには1つのページだと教えることができます。

注意点としてはページネーションです。1ページ目と2ページ目は全く異なるコンテンツが表示されるので別のページと考えると良さそうです。

また確実に検索結果から除きたいものはnoindexという別の仕組みを使うことができます。

next.jsの場合は全ページに以下のような設定をすればOK(./)

```tsx
export const metadata: Metadata = {
  alternates: { canonical: "/" },
};
```
