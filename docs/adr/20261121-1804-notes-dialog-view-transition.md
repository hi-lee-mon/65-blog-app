# 付箋の本文に高さの上限を付け、選ぶと ViewTransition でダイアログに広げて全文を見せる

- 日付: 2026-11-21
- 状態: 採用
- 関連: ADR `20261120-0040-notes-bento.md`（付箋の一覧）、ADR `20261120-0914-escape-hatch-rule.md`（エスケープハッチの決まり）

## 背景

3-3 の弁当レイアウトは、`grid-lanes` に対応していないブラウザでは行の高さが一番長い付箋にそろい、見づらい。高さを制限すると本文の続きが隠れるので、続きを読む方法も同時に要る。あわせて、React の `<ViewTransition>` を試したい。

## 決めたこと

1. `react` と `react-dom` を 19.3.1 に上げる
2. 本文だけを 12rem（`sizes.192`）で切り、下の 48 をぼかす
3. 一覧の本文は `inert` にする
4. 題を `<button>` にし、`::after` でカード全体を押せるようにする
5. ダイアログは HTML 標準の `<dialog>` と `showModal()` で作る
6. `<ViewTransition>` で動かすのはカードの枠だけにする。開いている間は枠の `<ViewTransition>` を外し、同じ名前を同時に2つ置かない。`share="auto"` と `default="none"` を付け、開閉以外の更新では動かさない
7. 背景を押して閉じる操作は `closedby="any"` で入れる。未対応の Safari には代替処理を足さず、「閉じる」ボタンで閉じてもらう
8. 動きを減らす設定では、View Transition のアニメーションをすべて止める
9. ダイアログの背景の暗さはブラウザの既定のままにする
10. 付箋ごとの URL は、この回では作らない
11. `z-index` の `[-1]` と、トークンだけの計算 `[min({sizes.640}, 100% - {spacing.32})]` は、エスケープハッチの決まりに沿って角かっこで書く
12. markuplint の `security/no-event-handler-attr` を全体で切る

## 採らなかった案

- **カードの中だけをスクロールさせる。** キーボードで操作しにくく、axe の `scrollable-region-focusable` に当たるおそれがある
- **カード全体を `<ViewTransition>` で出し入れする。** 中のボタンが作り直され、閉じたときにフォーカスの戻り先がなくなる
- **`document.startViewTransition` を直接使う。** React の更新との同期を自分で書くことになる
- **`@starting-style` で開く動きを付ける。** 手軽だが、カードの位置から広げられない
- **外側のクリックを `onClick` で自作する。** Safari でも閉じられるが、内側の余白のクリックやドラッグで誤って閉じないための処理が増える
- **markuplint の `overrides` で `.tsx` だけ規則を切る。** `.tsx` が検査から外れ、対象が38件から16件に減った

## 確認事項の推奨と欠点

- 高さの上限: 高さが 9〜12rem の短い本文でも、切れていないのに下が少し薄くなる
- `inert`: 読み上げの人には一覧で本文が読まれず、付箋を開く必要がある
- カード全体を押せる形: カードの中の文字を選択してコピーできない
- 枠を分ける形: 枠用の `div` と `z-index` が増える
- `closedby` だけで作る: Safari（iPhone を含む）では、外を押しても閉じない
- 動きをすべて止める: フェードのような穏やかな動きも止まる
- 背景の暗さが既定: 暗い表示では背景との差が小さい
- URL を作らない: 1枚だけを共有できず、ブラウザの「戻る」でもダイアログは閉じない
- markuplint の規則を切る: MDX に生の `onclick` を書いても止まらない

## 確かめた結果

2026-11-20 に、リポジトリの複製と Chromium で確かめた。

- 開くときと Esc で閉じるときの両方で、カードとダイアログが同じ名前でつながり 250ms 動いた
- Esc でも「閉じる」でも、押した付箋のボタンにフォーカスが戻った
- 動きを減らす設定では、付箋の動きが1つも始まらなかった
- `startTransition` を外すと、開くときの View Transition が始まらなかった
- 同じ名前を2つ置くと `Unexpected duplicate view-transition-name` が出た。ダイアログは開いた
- `bun run l`・`bun run b`・`bun run ay` が通り、ダイアログを開いた状態でも axe の違反は 0 件だった
- 2026-11-22 に開発サーバーの Chromium で、`closedby="any"` を確かめた。外を押すと縮む動きつきで閉じ、押した付箋のボタンにフォーカスが戻った。内側のクリックと、内側から外へのドラッグでは閉じなかった

未確認: Safari と Firefox での動き、VoiceOver の読み上げ、画面より長い本文のスクロール。`theme/tokens.ts` は読めないので、複製では `panda.config.ts` 側で同じトークンを足して確かめた。

## 今後

- 付箋を1枚だけ共有したくなったら、URL を持つダイアログ（Next.js の Intercepting Routes など）を検討する
- 背景の色と閉じるボタンの見た目は、ボタンの部品を作る回で整える
