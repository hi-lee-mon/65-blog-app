# コードの色付けはビルド時に Shiki で行う

- 日付: 2026-09-25
- 状態: 採用

## 背景

記事のコードブロックに色を付けるハイライターを決める必要があった。候補は Shiki と gpu-lexer の2つ。

## 決定

記事のコードブロックは、ビルド時に Shiki で色を付ける。unified の処理（`20260925-1914-unified-content-pipeline.md`）の中に組み込む。

## 理由

- ビルド時に色を付けた HTML を出力するので、ブラウザの対応状況に左右されない。JavaScript も配らずに済む
- 文法定義に基づいて色を付けるので、結果が正確

## 採らなかった案

- gpu-lexer（https://gpu-lexer.vercel.app/ ）: ブラウザ上で WebGPU の小さな AI モデルが色分けを推定する。2026-09 時点でバージョン 0.0.3 の実験的なライブラリ。WebGPU に対応していないブラウザでは色が付かず、Shiki との一致率も主要25言語で約87%にとどまるため、誰が読むか分からない記事には向かない。Lab で試す題材にはなる
