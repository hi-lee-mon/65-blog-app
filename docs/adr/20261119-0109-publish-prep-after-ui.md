# UI のあとに「公開の準備」の段を置き、記事・国際化はその後に回す

- 日付: 2026-11-19
- 状態: 採用
- 関連: ADR `20261115-2117-publishable-home-before-storybook.md`（公開できる見た目の段 3-0〜3-7）、設計書 `docs/design/20260925-blog-design-proposal.md` の「裏方」と「この先の予定」

## 背景

UI（3-0〜3-7）が終わったら、公開できる状態にしたい。記事もちゃんと置きたい。国際化はその次に考えたい（2026-11-19）。

ところが、設計書の「裏方」にある RSS・sitemap・404 ページと、AI が読みやすくする対応は、どの段にも入っていなかった。1-6・1-7・1-11 のチケットでは「この回では扱わない」として後回しにしていた。国際化は「この先の予定」に書いてあったが、時期は決めていなかった。

## 決めたこと

3-7 のあとに、公開の準備の段を 3-8 から 3-11 として足す。その後に記事の段（4-x）、国際化の段（5-x）を置く。

| Step | 内容                                                                                  |
| ---- | ------------------------------------------------------------------------------------- |
| 3-8  | RSS（`/feed.xml`）                                                                    |
| 3-9  | sitemap（`sitemap.xml`）                                                              |
| 3-10 | AI が読みやすくする対応。方式（`llms.txt` など）は、先行事例を調べてから ADR で決める |
| 3-11 | 404 ページ                                                                            |
| 4-x  | 記事を書いて置く。段の中身は、書き始めるときに決める                                  |
| 5-x  | 国際化（英語版）。設計書の「この先の予定」に従う                                      |

## 採らなかった案

- 記事の段を先にする: 記事が揃っても、RSS・sitemap がないと公開の形にならないため。
- 国際化を記事より前にする: 記事を日本語で揃えてから訳すほうが、訳す対象が決まるため。
