# トップ画面に自己紹介と最新の記事・付箋を置く

- 日付: 2026-11-22
- 状態: 採用
- 関連: ADR `20261122-1821-publish-first-path.md`（公開までの順番）

## 背景

トップ画面はリンクが3つ並ぶだけで、誰のどんなサイトかが分からない。ナビは「ノート」、ページの題は「付箋」で、同じページの呼び名も違う。

## 決めたこと

1. 自己紹介はトップ画面に短く置き、`/about` は作らない
2. 自己紹介の文章は、チケットの仮の文を本人が採用する
3. 記事と付箋を新しい順に3件ずつ並べる
4. 自己紹介、記事、付箋の順に置く
5. `NoteCard` に `headingLevel` を足し、既定を `h2`、トップ画面では `h3` にする
6. `/notes` の呼び名を「ふせん」にそろえる（本人の変更。チケットの推奨は「付箋」）
7. デザインシステムへのリンクはトップ画面から外し、フッターだけに残す

## 採らなかった案

- **`/about` に自己紹介を分ける。** 経歴を詳しく書けるが、ページが増えて公開が遅れる
- **フッターに1行だけ置く。** 場所を取らないが、誰のサイトかが最初に伝わりにくい
- **トップ画面の付箋を `h2` のままにする。** 部品は変えずに済むが、「最新の付箋」と各付箋が同じ階層になる

## 確認事項の推奨と欠点

- 自己紹介をトップ画面に置く: 長い経歴を書く場所がない
- 仮の文を採用する: 書き手の経歴や関心はまだ伝わらない
- 3件ずつ並べる: 4件目以降を読むには一覧へ移動する
- 自己紹介、記事、付箋の順: 付箋がスマートフォンで下のほうになる
- `headingLevel` を足す: 部品の props が1つ増える
- 「ふせん」にそろえる: 過去のチケットや ADR の「付箋」と表記が違う
- デザインシステムのリンクを外す: トップ画面からの導線が目立たなくなる

## 確かめた結果

2026-11-22 に、リポジトリの複製でチケットの手順を流した（next 16.4.6、react 19.3.1、bun 1.4.4、Node.js 24.22.1）。

- 320px、375px、1280px の幅で横スクロールは出ず、見出しは `h1`、`h2`、`h3` の順に並んだ
- 付箋を Enter で開いて Esc で閉じると、フォーカスが同じ付箋の題に戻った
- `bun run l`、`bun run fc`、`bun run tc`、`bun run ay` が通った
- `headingLevel="h4"` にすると `bun run tc` が `TS2322` で失敗した
- `aria-labelledby` の `id` を打ち間違えても `bun run ay` は通った
